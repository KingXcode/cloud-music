# 云听 · Cloud Music

基于 Flutter 的音乐播放器，直接播放原始音频文件，支持 iPhone、iPad、macOS、Android（包括可安装普通 APK 的车机）和浏览器。

[打开网页版](https://kingxcode.github.io/cloud-music/) · [源码仓库](https://github.com/KingXcode/cloud-music) · [构建状态](https://github.com/KingXcode/cloud-music/actions)

## 功能介绍

- 0.6.0 起增加“应用更新”：自动检查、真实下载进度、取消/重试和下载完成提示。Android 经系统安装器确认；macOS 打开校验后的 DMG（尚非自动替换/重启）；网页下载完成后确认重载。源码功能不代表已发布，签名与平台限制见[版本更新说明](docs/APP_UPDATES.md)。

- iCloud 目录分批展示歌曲，Apple 原生端用系统属性标记未下载并按点播请求下载；网页按浏览器能力先列名称、点播读取，不虚构 iCloud 下载状态。Safari/iOS 选择器可能提前下载，详见 [按需读取与平台限制](docs/ICLOUD_ON_DEMAND.md)。

- 新增「音乐来源」入口与 Google Drive 官方只读接入代码：授权后浏览音乐目录、建立会话曲库和播放。**需要开发者 OAuth Client ID；未配置版本不能直接登录，真实账号/设备尚未联调。** 详见 [Google Drive 配置和限制](docs/GOOGLE_DRIVE.md)。
- Android 新增显式「扫描本机音乐」，经用户授予音乐读取权限后读取系统媒体库；未收录的音乐或 U 盘仍可选文件夹。拒绝权限、空扫描和读取失败不会清空原曲库。详见[文件夹选择与本机扫描](docs/LOCAL_MUSIC_IMPORT.md)。
- 在 Apple 设备上选择 iCloud Drive 文件夹，或通过 Android 系统选择器选择本地、USB 目录。
- 保存访问权限和元数据索引，通过原始 URL/URI 播放，不将歌曲复制到应用沙盒。
- 恢复文件夹书签和 Android 存储访问框架（SAF）的持久权限。浏览器在支持且获准时记住目录句柄，其他浏览器会在需要时提示重新选择。
- 浅色音乐资料库支持歌曲、专辑、歌手分类、搜索、可用状态标记和手动刷新；手机底部导航在宽屏切换为侧栏。
- 自动识别歌名/歌手；一次开启自动歌词后，随当前歌曲搜索 LRCLIB，可靠匹配自动缓存，不确定时提供版本预览再保存、繁简标签回退与可切换的简体显示、LRC 同步高亮与跳转、离线缓存及本地 LRC/TXT 导入。详见[歌词使用、隐私与版权限制](docs/LYRICS.md)。
- 浮动迷你播放器与沉浸式完整播放器，支持柔和背景、封面占位图、元数据、进度跳转、待播清单、上一首/下一首、播放/暂停、随机播放、循环播放和音量调节。
- 可调字号的同步歌词，默认 22、支持 14–36，当前句居中高亮；手动滚动后可返回跟随，点击歌词行即可跳转。搜索、导入与粘贴收纳到歌词选项面板，宽屏可同时显示封面、控制与歌词。
- 适配窄屏、横屏和宽屏布局，提供更大的触控区域。本应用**不是 Android Auto 应用**。请勿在驾驶时操作。
- 启动时校验已知歌曲；刷新时发现新歌曲，只移除已确认缺失的索引条目。iCloud 离线、文件提供器报错、权限撤销或 USB 断开都不会清空音乐库，应用始终不会删除源文件。

## 使用限制与说明

应用不会上传音频。浏览器通过临时 Blob URL 播放音频；Google Drive 网页版会完整缓冲当前一首歌（最多 100 MiB）后播放，原生使用受保护 HTTPS 串流。Apple iCloud/文件提供器可能将原始文件下载到系统管理的设备存储中，因此播放仍会占用设备空间。应用保存元数据、访问凭据，以及用户选择下载或导入的歌词。自动歌词默认关闭。首次同意开启后，播放时只向 LRCLIB 发送当前歌曲的歌名、歌手和可选专辑，后续无需逐曲确认；可随时关闭。不会上传音频、路径或时长。

支持的音频格式取决于 AVFoundation、Android 编解码器和浏览器。文件扩展名仅用于发现候选音频，不能保证一定可以解码。原生端只按需加载所选歌曲的封面和元数据；网页版播放时在本地读取 ID3、FLAC/Vorbis、Ogg/Opus、M4A 标签，标签缺失则智能拆分文件名，使用默认封面。

本仓库目前处于早期可用阶段。自动化测试不能替代真实设备上的 iCloud、USB、车机和后台音频测试。验收项目见各平台实现说明及 `docs/REQUIREMENTS.md`。

## 本地运行

使用 Flutter **3.47.5**（Dart 3.13.4），然后执行：

```sh
flutter pub get
flutter analyze
flutter test
node --test test/web/*.cjs
flutter run -d chrome
```

在本地浏览器使用文件夹选择器时，请通过 localhost 或 HTTPS 提供服务。桌面版 Chrome/Edge 对 File System Access 持久访问的支持最完整。支持目录输入的 Safari（含 iPhone/iPad Safari 18.4+）可选择整个文件夹；同时保留多个文件选择，旧版 iOS 和不支持目录的浏览器使用多选回退。详见 `docs/WEB_PLAYBACK.md`。

```sh
flutter run -d macos       # 需要 macOS 和 Xcode
flutter run -d ios         # 选择已配置签名的 iPhone/iPad 或模拟器设备 ID
flutter build apk --release --target-platform android-arm,android-arm64,android-x64
flutter build macos --release
bash scripts/package_macos.sh
```

Android 最低要求为 API 24。Apple 插件支持 iOS 15 / macOS 12 及以上版本。Apple 真机测试需要适当的签名配置和 iCloud 账号。仓库包含 iOS 源码，但不提供已签名的 iOS 安装包。

Android 发布配置目前使用标准调试/测试签名密钥，因此安装包明确标记为测试签名。正式公开发行前，须换用妥善管理的生产密钥。新的 CI 构建可能使用不同密钥，届时可能需要重新安装预览版。

## GitHub 交付流程

- 网页部署工作流（`Deploy Web to GitHub Pages`）：推送到 main 分支或手动触发时，执行校验、构建并部署网页版。Pages 基础路径随仓库名称设置。仓库须支持 Pages，并允许工作流所需权限。
- 原生打包工作流（`Build APK and macOS DMG`）：手动触发时指定新的预览版标签，并将平台设为 `all`。选择 `android` 时仅构建、验证 APK 产物，不发布版本。Linux 构建通用 APK，托管 macOS 编译应用并生成 DMG。流程会验证 APK 签名和包内容、检查应用可执行文件及签名、验证 DMG、生成 SHA-256 校验值，只有两个原生构建任务都成功后才发布预发布版本。
- macOS DMG 未签名，应用未使用 Developer ID 签名，也未经过 Apple 公证；可能带有本地临时签名（ad-hoc）。发布信息会列出实际包含的 CPU 架构。

本仓库不保存证书、生产签名密钥或用户音乐。

## 代码结构

- `lib/ui/`：自适应 Flutter 音乐库和播放器界面。
- `lib/music_controller.dart`、`lib/models.dart`：带类型约束的界面状态与命令处理。
- `lib/gateway/`：原生通道适配器、浏览器桥接与来源切换。
- `lib/drive/`：Google Drive 官方 OAuth、只读 API、会话曲库及平台音频适配。
- `packages/folder_audio/darwin/`：Apple 平台共享的 Swift 书签、文件协调、iCloud 和 AVPlayer 实现。
- `packages/folder_audio/android/`：SAF 扫描器、原始 URI 播放器和媒体前台服务。
- `web/music_gateway.js`：浏览器句柄持久化和本地音频播放。
- `docs/BRIDGE_CONTRACT.md`：平台接口约定。

## 歌词更新前的验证状态

云端工作区已通过：Flutter 静态分析、17 项单元/组件测试（包括窄屏、横屏、宽屏和大字体布局）、25 项浏览器逻辑测试、JavaScript 语法检查及 Web 发布构建。Android/macOS 原生构建和安装包检查由 GitHub 发布工作流执行，须查看实际结果；仅源码检查通过不能证明编译成功。真机访问与播放测试仍需单独进行。

已部署网页版的冒烟测试验证了页面布局、完整播放器跳转、文件提供器错误提示，以及循环/随机播放偏好的恢复。自动化浏览器无法打开系统文件夹选择器，因此其中的真实目录选择、音频播放和句柄恢复尚未验证。

歌词验证情况和原生设备检查另见[歌词文档](docs/LYRICS.md)。

## 0.3.0 界面改版

新版参考 Apple Music 的视觉层次与操作习惯，但保留云听的原文件播放定位。改版说明与验证范围见[界面改版记录](docs/UI_REDESIGN.md)。文件夹权限、播放网关、歌词联网确认和缓存规则均保持原有机制。


## 0.4.0 自动歌词与歌曲识别

- 文件内标签优先，缺失时拆分 `S0015 张靓颖 - 天下无双` 等文件名，显示正确歌名和歌手，保留 Live / remix 等版本信息。
- 在歌词页点“开启自动歌词”，一次同意后随歌曲自动搜索。歌名、完整歌手、版本及相差不超过 3 秒的时长均匹配且无歧义，才自动缓存。
- 标签和时长稍后加载、快速切歌、取消、关闭自动搜索均有竞态保护；离线缓存优先，不覆盖手动选择或导入的歌词。
- 未匹配或多版本时给出候选，支持手动修改搜索和导入；不会联网扫描整个资料库。

## 0.5.0 Google Drive 来源

新增系统文件 / Google Drive 来源切换、只读授权、递归目录索引、会话播放与错误恢复。网页和 Android CI 可通过 repository variables 提供公开客户端 ID；未配置时明确禁用直接登录。没有创建开发者账户、生成凭据或执行真实 Google 授权。详见 [接入与验收边界](docs/GOOGLE_DRIVE.md)。


## 0.6.1 歌词搜索与文字显示

搜索会逐步忽略专辑、尝试繁简字形；歌手未知时允许手动按歌名查找。候选可筛选同步歌词，先预览再保存，明确提示时长/版本差异。默认本地简体显示，可切回原文，原始歌词和时间轴均保留。LRCLIB 仍可能未收录部分歌曲，可导入 LRC / TXT 作为补充。详见[歌词优化与验证边界](docs/LYRICS.md#歌词搜索与显示优化)。

## 0.6.2 短音频过滤

资料库新增“短音频过滤”，默认隐藏已知时长不足 30 秒的音频，可调整为 1–600 秒或关闭。歌曲、专辑、歌手和搜索共用设置，本机持久保存。未知时长暂时保留，播放补全时长后更新显示；不会仅为测量时长读取或下载云端音频，也不删除源文件或改动当前播放与待播清单。详见[过滤规则与验证](docs/SHORT_AUDIO_FILTER.md)。

## 0.6.3 资料库与音乐导入

手机资料库精简为标题、分类和单行播放操作，打开即可看到歌曲。低频管理操作收进资料库选项，搜索独立，未播放时不显示占位播放器。支持按平台能力区分文件夹、多选文件和 Android 本机音乐扫描入口。查看[资料库改版说明](docs/UI_REDESIGN.md#063-资料库首屏与添加音乐)。

## 0.7.0 全页面 Cupertino

资料库、播放器、搜索、歌词、导入、来源、过滤、更新与确认弹层全部改为 Cupertino 组件，移除 Material 控件及字体依赖，保留跨平台布局、原有音乐操作和中文系统文案。完整清单与验证边界见[Cupertino 迁移说明](docs/CUPERTINO_UI.md)。

## 0.7.1 歌词字号

歌词默认缩小到 22，点击歌词标题旁的 **Aa** 可随时调整为 14–36，实时预览、恢复默认，并自动记住本机选择。同步歌词、纯文本和宽窄屏共用字号，仍尊重系统文字缩放；跟随播放时调整字号会重新对齐当前句，手动浏览时不抢回滚动位置。不会改动原始歌词、时间轴或音频文件。详见[歌词字号说明](docs/LYRICS.md#歌词字号)。

## 0.7.2 歌词搜索改版与网页同步修复

歌词搜索采用新的 Cupertino 分层表单与版本卡片，支持片段预览、固定确认按钮和明确的纯文本提示。修复 Web 编译后时长与歌词时间轴被错误归零的问题，让真实时长、播放进度及逐行跟随恢复正确计算。详见[歌词说明](docs/LYRICS.md)。
