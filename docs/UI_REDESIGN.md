# 0.3.0 界面与交互改版

## 设计与使用

- 资料库采用浅色背景、红色强调和清晰字重。歌曲、专辑、歌手分类及搜索均使用现有元数据，不虚构推荐、订阅或在线音乐内容。
- 手机底部提供资料库与搜索入口，平板、桌面和较宽横屏改为侧栏。迷你播放器始终保留，点击展开全屏播放器。
- 手机默认展示封面；歌词和待播清单通过底部按钮切换。宽屏默认将封面、播放控制与歌词并排显示。顶部向下箭头返回资料库，系统返回同样有效。
- 歌词采用大字号和当前句高亮，自动居中跟随。手动拖动后暂停跟随，点击“回到当前歌词”可恢复；点击歌词行跳转并恢复跟随。此版本仍是逐行同步，不是逐字卡拉 OK 时间轴。
- 歌词搜索、导入、粘贴与版本选择收纳到“歌词选项”面板。每次在线搜索仍需核对并确认发送给 LRCLIB 的字段，打开歌词界面不会自动发起网络请求。
- 完整播放器保留上一首、播放/暂停、下一首、进度、音量、随机与循环。紧凑横屏通过音量按钮打开独立滑杆，避免挤压主要播放控制。
- 待播清单显示当前资料库。随机模式明确说明列表仍以资料库顺序展示，不伪装成可预测的随机播放顺序。
- 专辑和歌手分类使用文件已有元数据。当前 Web 网关只读取文件名，没有标签时显示未知专辑/歌手；改版没有改变这一限制。

## 安全与数据边界

未改动文件夹授权、音频读取、原文件播放、刷新删除判定、外部歌词同意、离线缓存或源目录写入规则。音频不上传，原文件不删除。没有将测试歌曲或测试歌词加入正式应用。

## 验证

本地执行 Flutter 静态分析、完整单元/组件测试、浏览器网关 Node 测试、JavaScript 语法检查和 Web release 构建。视觉检查通过真实 Flutter 渲染导出测试截图，覆盖 390×844 手机、1440×900 桌面和 844×390 横屏；组件布局还覆盖 320×640、1024×768 和 1.8 倍字号。

新增回归覆盖分类导航、精确歌曲选择、搜索状态、重复打开播放器、系统返回、歌词/队列切换、横屏音量和歌词手动滚动/恢复跟随。

本地 Chromium 启动受执行环境权限限制，浏览器专用歌词回归以 GitHub CI 实际结果为准。Android 构建、桥接 JVM 测试及 APK 签名/包名/架构校验由发布流水线执行。真实 iCloud、USB、后台音频和车机触控仍需设备验证。本次不声称提供 iOS 签名包或已验证的 macOS 安装包。

运行本地视觉检查（仅测试环境）：

```sh
CLOUD_MUSIC_CAPTURE_DIR=/tmp/cloud-music-qa flutter test test/ui_visual_capture_test.dart
```

视觉检查使用原创虚构内容，不包含真实用户音乐。
