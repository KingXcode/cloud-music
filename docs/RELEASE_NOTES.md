## 弦泊 · Xianbo 0.7.7 预览版

本次简化歌曲列表，增加播放次数统计与列表排序。macOS、Android 和 Web 同步更新至 0.7.7。

- 正常歌曲不再显示“内容可用”等状态标签；暂时不可用、文件缺失、需要重新授权或格式不支持的歌曲以灰色显示。正在加载时保留进度提示。
- 每次实际开始播放计为 1 次；暂停后继续、缓冲恢复、进度更新和拖动进度不重复计数。重新播放、切换歌曲和单曲循环重新开始会累加；加载失败或取消加载不计数。歌曲列表与待播清单显示已有播放次数。
- 列表增加资料库顺序、歌曲名称、歌手、专辑、时长和播放次数排序。支持升序、降序；选择播放次数时默认从多到少。歌曲、搜索结果和专辑／歌手内的歌曲列表共用当前排序。
- Apple 设备可在“资料库选项 → 播放统计 → 选择个人 iCloud 文件夹”中，选择或新建个人 iCloud Drive 下的“弦泊”文件夹，保存 `playback-stats.json`。选择后合并已有统计，系统负责同步；其他设备选择同一同步文件夹后可合并各自的计数。也可选择普通本地文件夹，界面会显示实际选择的文件夹保存方式。
- 未选择统计文件夹时，Apple 设备先保存到本机；Android 保存在本机，Web 保存在当前浏览器。仅播放统计写入所选统计文件夹，音频仍从原音乐来源播放。

保留上一版的 macOS 浏览器下载更新方式：应用内“前往官网下载”会打开对应版本的 GitHub 发布页，由浏览器下载 DMG。Android 和 Web 保留原有更新方式。

macOS 安装包内应用现在为 `Xianbo.app`。从旧版升级时先退出 `CloudMusic.app`，安装并确认原曲库正常后再将旧应用移到废纸篓，避免重复打开；保留原应用数据和音乐目录。包标识、资料存储位置及更新资源地址继续兼容旧版。

如果之前通过旧版应用内更新下载了 DMG，请在浏览器中重新下载本版本，再拖入“应用程序”。旧缓存中的受限文件不会因升级自动恢复。保留本机歌曲后台时长补齐功能。

直接播放文件夹中原始音频的音乐播放器，提供音乐库、常驻迷你播放器和独立的正在播放页面。

- Android：通过系统选择器选择本地或 USB 文件夹，文件提供器支持时会持久保存权限。APK 使用标准调试/测试签名，未使用生产签名身份。后续版本可能需要先卸载此预览版再安装。
- macOS：通过安全作用域书签访问所选文件夹，包括 iCloud Drive。DMG 未签名，应用未使用 Developer ID 签名，也未经过 Apple 公证；可能带有本地临时签名（ad-hoc）。实际构建架构见 macos-architectures.txt。
- Web：本地播放，不上传音频。受支持的浏览器可记住目录句柄，不具备该能力的浏览器会在需要时要求选择文件夹。访问权限可能过期或被撤销。
- 包含 iOS/iPadOS 源码，但不提供已签名的 iOS 安装包。

应用保存文件夹权限和元数据，不复制整个音频库。iCloud/文件提供器可能将原始文件下载到系统管理的存储中。刷新绝不删除源文件，离线、文件提供器报错和 USB 设备断开都不会被视为已确认删除。

这是预览版，尚非通过设备验证的正式生产版本。CI 通过表明编译、自动化测试和安装包检查通过；个人 iCloud Drive 的真实账号同步、跨设备同步时序尚未实机验证，上传与下载由系统调度。每种车机上的 USB 行为、硬件音频输出及所有设备上的连续后台播放也需要实际设备验证。请勿在驾驶时操作界面。

APK 和 DMG 的 SHA-256 校验值见 SHA256SUMS.txt。音频格式支持取决于各平台的编解码器。
